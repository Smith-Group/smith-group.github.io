# Convert a list of parameters for use with make_fit_input

Convert a list of parameters for use with make_fit_input

## Usage

``` r
param_list_to_arg_list(param_list)
```

## Arguments

- param_list:

  parameter list

## Value

A flattened, named \`list\` of arguments suitable for \`do.call()\` with
\`make_fit_input()\`.
