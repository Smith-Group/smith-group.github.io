# Combine multi-dimensional arrays with lists

Combine multi-dimensional arrays with lists

## Usage

``` r
abind_list(..., rev.along = NULL)
```

## Arguments

- ...:

  any number of lists with dimensions or a single list of list arrrays

- rev.along:

  dimension to reverse before binding (passed to
  [`abind`](https://rdrr.io/pkg/abind/man/abind.html))
