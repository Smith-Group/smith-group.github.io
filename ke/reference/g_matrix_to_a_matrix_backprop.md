# Back-propagate energy derivative from a matrix to g matrix

Back-propagate energy derivative from a matrix to g matrix

## Usage

``` r
g_matrix_to_a_matrix_backprop(a_coef, d_energy_d_a_matrix)
```

## Arguments

- a_coef:

  coefficients used for calculating a values

- d_energy_d_a_matrix:

  matrix (pairs, eigenvalues)

## Value

matrix (pairs, groupings) with d_energy_d_g_matrix
