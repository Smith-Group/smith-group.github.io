# Get the first index in the omega0 array corresponding to each TRUE value in omega0_idx

Get the first index in the omega0 array corresponding to each TRUE value
in omega0_idx

## Usage

``` r
omega0_comb_source_idx(param_list, omega0_idx = omega0_param_idx(param_list))
```

## Arguments

- param_list:

  parameter list

- omega0_idx:

  logical index list for omega0 parameters
