# Quadratic loss function

Quadratic loss function

## Usage

``` r
quadratic_loss(x, x0, k = 1, gradient = FALSE)
```

## Arguments

- x:

  current values

- x0:

  target values

- k:

  force constant

- gradient:

  a logical value indicating whether to calculate the derivative

## Value

\$\$k(x - x_0)^2\$\$
