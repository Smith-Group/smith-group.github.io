# Read an NMRDraw formatted peak table

Read an NMRDraw formatted peak table

## Usage

``` r
read_nmrdraw_peak_tab(file_path)
```

## Arguments

- file_path:

  path to the NMRDraw peak table file

## Value

A \`data.frame\` containing the peak table, with columns defined by the
\`VARS\` line in the NMRDraw file.
