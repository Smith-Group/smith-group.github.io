# Build spectral-density relaxation data from expanded atom-pair input

This function constructs the matrices that implement a user-supplied
kinetic model for a given number of ensemble members. It converts
expanded atom-pair input, together with the corresponding
`relax_data_list`, into the heterogeneous data structure needed for
spectral-density relaxation calculations.

## Usage

``` r
make_spec_den_relax_data(
  atom_relax_data,
  base_rate_mat,
  base_rates,
  perm_rates = c(NA_real_, NA_real_)
)
```

## Arguments

- atom_relax_data:

  heterogeneous list with at least `atom_pairs`, `unit`, and
  `relax_data_list`

- base_rate_mat:

  transition-rate matrix for ensemble-member exchange

- base_rates:

  named numeric vector of symbolic base-process rates used to label
  `lambda_int_coef`

- perm_rates:

  length-two numeric vector describing permutation processes on the `a1`
  and `a2` sides. `NA` indicates no permutation, while a non-missing
  named value supplies the symbolic rate constant for the inferred
  permutation on that side.

## Value

A list with elements `atom_pairs`, `unit`, `relax_data_list`,
`groupings`, `a_int_coef`, `lambda_int_coef`, and
`inferred_multiplicity`

## Details

The function infers the permutation block layout, if any, from the
atom-pair row ordering, validates that all blocks follow the same
Cartesian-product structure, and constructs the internal-motion grouping
and coefficient matrices from `base_rate_mat` and `perm_rates`. The
spectral-density term arrays in `relax_data_list` are passed through
unchanged.

The resulting object is intended to work with any rate definition
encoded in `relax_data_list`, including term arrays generated by
[`make_sigma_spec_den_term_array()`](https://smith-group.github.io/ke/reference/make_sigma_spec_den_term_array.md),
[`make_r1_spec_den_term_array()`](https://smith-group.github.io/ke/reference/make_r1_spec_den_term_array.md),
[`make_r2_spec_den_term_array()`](https://smith-group.github.io/ke/reference/make_r2_spec_den_term_array.md),
or other functions that produce the same `spec_den_term_array`
structure.

The current implementation assumes that the rows in `atom_pairs` follow
the expanded ordering convention where rows belonging to the same
relaxation-rate are separated by \\N\\, the number of relaxation-rates.
Reordering rows breaks this interpretation and causes validation to
fail.
