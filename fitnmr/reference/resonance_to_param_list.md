# Convert data frame of resonances into a parameter list

Convert data frame of resonances into a parameter list

## Usage

``` r
resonance_to_param_list(spec, resonance, nuclei, couplings)
```

## Arguments

- spec:

  single spectrum

- resonance:

  data frame with resonances

- nuclei:

  data frame with nuclei chemical shifts and R2 rates

- couplings:

  data frame with scalar couplings
